# Voxel TV Streams

Repositorio de archivos de streaming para Voxel TV.

## Archivos

Este repositorio contiene archivos de streaming en formato DASH (.mpd) para la aplicación Voxel TV.

## Uso

Los archivos están disponibles vía GitHub Pages en:
`https://ignac16.github.io/voxel-tv-streams/`

Ejemplo de uso:
```
https://ignac16.github.io/voxel-tv-streams/a3s.mpd
```
